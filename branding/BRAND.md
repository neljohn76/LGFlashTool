# LGFlashTool identity

The supplied LGFlashTool reference logo is now the product identity: a rounded pale-aqua tile with a dark teal LG lightning/transfer mark and the `LGFlashTool` wordmark. The in-app header and launcher use the extracted mark, while the original reference image is preserved at `branding/LGFlashTool-reference-logo.jpg`.

The dashboard uses dark graphite surfaces with a pale-aqua active data accent and crimson destructive flash action. The palette keeps the brand legible on AMOLED screens while making the primary flashing action unmistakable.

- Signature aqua: `#7DE3E8`
- Graphite: `#273142`
- Crimson flash action: `#E4003B`
- Dark surface: `#10131B`
- Typography: Android system sans for product UI; monospace for protocol logs

The Android UI uses the same symbol in the app header and launcher icon, with a night resource variant that lifts the graphite geometry for contrast. Flashing behavior, USB communication, and firmware parsing remain in the existing native Kotlin modules.
